# FlowIn 智慧報到系統

這是一個以 React + Vite 建立的企業級智慧報到原型。產品以 Check-in / Check-out 為核心，透過場景模板支援企業內訓、講座、展覽、會議、考試、員工活動與門禁入場。

## 執行

```bash
npm install
npm run dev
```

預設網址為 `http://127.0.0.1:4173`。

## 驗證

```bash
npm test
npm run build
```

## 專案結構

- `src/domain/`: 報到規則與場景模板，不依賴 UI。
- `src/data/`: 展示活動與人員資料。
- `src/components/`: sidebar、topbar、報到工作台與管理頁面。
- `src/i18n.js`: 中英文介面字典。
- `tests/`: 報到核心情境測試。
- `reference/`: 使用者提供的來源 JSX 與舊版原型，只作設計參考，不參與執行。

## 設計原則

- 現場工作以報到判定與下一步指引為主，進階資訊放在獨立頁面。
- 狀態色只用於成功、警告、錯誤與處理中，不作大面積裝飾。
- 場景差異由模板與規則層處理，避免在 UI 散落條件判斷。
- 所有展示資料均為前端記憶體資料，正式上線前需串接身分、活動與稽核後端。
