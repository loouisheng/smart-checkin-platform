# 給公司內部 AI 的 Prompt(可直接複製貼上)

> 適用於「聊天介面」的開源模型(如 Qwen/DeepSeek 等)。
> **重要:開源模型 context 有限,一次只餵一個檔案 / 一小段。** 每個 prompt 都已加上「只改外觀、不要動邏輯」的護欄。
> 這些是**輔助**;最準的萃取仍是用瀏覽器 F12 抽查核對。

---

## Prompt A — 從初版 HTML 萃取設計規格

> 用途:把初版 `reference.html` 的視覺,整理成一份設計規格。
> 用法:把下面整段貼上,再把初版 HTML 原始碼接在最後。

```
你是資深前端工程師。以下是一份靜態 UI 設計稿的 HTML/CSS 原始碼。
請只做「設計規格萃取」,不要重寫程式、不要評論。

請輸出以下欄位,每項給出精準值(色碼用 hex,數值帶單位);
若原始碼中找不到,就寫「未指定」:

【顏色】
- 主色(主要按鈕底色 / 連結色):
- 主色-深(hover 或強調):
- 主要文字色:
- 次要文字色(說明、標籤):
- 整頁背景色:
- 卡片/面板背景色:
- 邊框線色:
- 主色的淡色底(標籤、選中背景):
- 危險/刪除色:
- 成功/提示色:

【字型】
- 中文字型:
- 英文字型:
- 標題字重:
- 內文字級:

【形狀】
- 按鈕圓角:
- 卡片圓角:
- 輸入框圓角:
- 卡片陰影(box-shadow 值):

【版面】
- 側邊欄:深色底還是白底?寬度?

- 頂欄高度與背景:
- 主要按鈕是「實心填色」還是「外框」?

最後用一段話總結這個設計的整體風格(例如:偏企業藍、圓角柔和、卡片有淺陰影)。

===== 以下是原始碼 =====
```

## Prompt B — 產生某個 CSS 檔的「換色」修改

> 用途:把一個 CSS 檔改成新配色。
> 用法:填入「換色對照表」(從 `03-design-spec.md` 抄),再貼上**一個** CSS 檔的內容。

```
你是資深前端工程師。任務:只更新這個 CSS 檔的「顏色」以套用新配色。

嚴格規則:
1. 只改顏色值(hex / rgb / rgba)。不要改任何選擇器名稱、版面、間距、字級、動畫。
2. 邏輯與結構完全不動。
3. 依下面的對照表做替換;表中沒列到的顏色維持原樣。
4. 直接輸出改好的完整 CSS,不要解釋。

【換色對照表(舊 → 新)】

#1d4ed8 -> <新主色-深>
#1e40af -> <新深色>

#172033 -> <新主要文字>
#667085 -> <新次要文字>
#e4e9f1 -> <新邊框>
#bfdbfe -> <新主色邊框>
<...其餘依 03-design-spec.md 補上...>

===== 以下是要修改的 CSS 檔 =====
<在這裡貼上一個 .css 檔的完整內容>
```

## Prompt C — 逐元件微調(對照截圖 / 描述)

> 用途:某個元件外觀還不像初版時,單獨微調它。
> 用法:貼上該元件的 JSX 與相關 CSS,並用文字描述初版長怎樣(或附截圖給支援看圖的模型)。

```
你是資深前端工程師。以下是一個 React 元件與它的 CSS。
我要讓它的外觀符合公司初版設計,描述如下:
<用文字描述初版這個元件的樣子:例如「按鈕是白底藍框、圓角較大、無陰影」>

嚴格規則:
1. 只調整外觀(CSS,必要時微調 JSX 的 className 或包裹結構)。
2. 不要改任何資料處理、事件邏輯、文字內容、匯入項目。
3. 保持所有現有功能可運作。
4. 輸出:改動後的 CSS(與必要的 JSX 片段),並簡短說明改了哪幾行。

===== JSX =====
<貼上元件 .jsx>

===== CSS =====
<貼上相關 .css>
```

## Prompt D —(選用)產生設計 token 檔

> 用途:若想把新配色集中成一個變數檔,方便日後再調。

```
你是資深前端工程師。根據下面的設計規格,產生一個 theme.css,
把所有顏色、圓角、陰影定義成 CSS 變數(:root 底下),命名清楚(例如 --color-primary、--radius-card、--shadow-card)。
只輸出 theme.css 內容,不要解釋。

【設計規格】
<把 03-design-spec.md 填好的內容貼上>
```

### 使用這些 Prompt 的通則

- **一次一個檔**。貼太多會超出開源模型的 context,結果會亂。
- 模型輸出後,**貼回編輯器前先掃一眼**:有沒有不小心改到選擇器名稱、有沒有漏東西。
- 改完一個檔就存檔、看瀏覽器、和初版對照,再進下一個。
- 若模型能力不足導致結果不理想,就**改用手動找替換**(對照表照著換即可,不一定要靠 AI)。
